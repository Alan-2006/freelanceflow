FreelanceFlow REST API Reference

JSON endpoints for programmatic access to clients, projects, milestones, invoices, and payments.

v1.0.0

Authentication & Headers

All API endpoints require session authentication or HTTP Basic Auth. Each freelancer only has access to their own tenant data.

Authorization: Basic <base64_encoded_email:password>
Content-Type: application/json

API Resource Endpoints

GET POST /api/v1/clients/
List and create clients

Query parameters: ?page=1

{ "name": "Jane Doe", "company": "Design Hub", "email": "jane@designhub.dev", "currency": "USD" }
GET POST /api/v1/projects/
Manage projects and roadmap progress
{ "client": "<uuid>", "title": "E-Commerce App", "budget": "8000.00", "billing_type": "Fixed" }
GET POST /api/v1/invoices/
Query invoices, track status, and line items

Provides live balance_due and nested line items.

GET /api/v1/payments/
Read settled receipts and transactions
GET POST /api/v1/timesheets/
Log and manage tracked billable hours and durations
GET POST /api/v1/expenses/
Track overhead, software subscriptions, and project expenses
